# Internationalisation (i18n) — DailyOps.Tech

**Toute page publique est sous `/en/...` ou `/fr/...`.**

## Règle d’or

| Faire | Éviter |
|-------|--------|
| Liens : `lp("/articles")` depuis `useLanguage()` | `href="/articles"` en dur |
| Meta : path **sans** locale + `{ lang }` | Canonical `/articles` sans `/en` |
| Switch FR/EN : `setLang("FR")` | Changer la langue sans changer l’URL |

---

## URLs publiques

| Page | EN | FR |
|------|----|----|
| Home | `/en` | `/fr` |
| Articles | `/en/articles` | `/fr/articles` |
| Article | `/en/articles/<slug>` | `/fr/articles/<slug>` |
| Labs | `/en/labs` | `/fr/labs` |
| Lab | `/en/labs/<slug>` | `/fr/labs/<slug>` |
| Catégorie | `/en/category/<slug>` | `/fr/category/<slug>` |
| Experience | `/en/experience` … | `/fr/experience` … |
| Products | `/en/products` | `/fr/products` |
| About | `/en/about` | `/fr/about` |
| Resources | `/en/resources` | `/fr/resources` |
| Privacy / Legal | `/en/privacy`, `/en/legal` | `/fr/privacy`, `/fr/legal` |

### Comportement proxy (ex-middleware)

| Requête | Résultat |
|---------|----------|
| `/articles` | **308** → `/en/articles` |
| `/index.html`, `/index.php`, `/default.htm`… | **308** → `/en` (home canonique) |
| `/fr/labs/soc-first-30-days` | **rewrite** interne → `/labs/soc-first-30-days` + `x-locale: fr` |
| `/en/about` | **rewrite** → `/about` + `x-locale: en` |
| `/url/inconnue` | **404** direct (pas de redirect locale) |
| `/api/*`, `/feed.xml`, OG images | pas de locale |

Seules les routes de contenu connues (`/articles`, `/category/*`, `/labs/*`, `/about`, `/contact`, `/products`, …) reçoivent le redirect locale ; le reste renvoie un vrai 404.

Les fichiers pages restent dans `src/app/articles/`, `src/app/labs/`, etc.  
**Tu ne crées pas** `app/en/` ni `app/fr/` (sauf si tu changes l’archi).

## Comment écrire un lien

```tsx
"use client";
const { lp, lang, setLang } = useLanguage();

<Link href={lp("/articles")}>Articles</Link>
<Link href={lp(`/articles/${slug}`)}>…</Link>
<Link href={lp("/about#contact")}>Contact</Link>
```

Labs :

```ts
buildLabArticleHref(pathSlug, stepId, articleSlug, lang);
buildLabPathHref(pathSlug, lang);
```

## Metadata (Server)

```ts
export async function generateMetadata(): Promise<Metadata> {
  const lang = await getRequestLanguage(); // header x-locale
  return pageMetadata(
    tLang(lang, "about.title"),
    tLang(lang, "about.subtitle"),
    "/about", // SANS /en|/fr
    { lang }
  );
}
```

Articles :

```ts
articleMetadata(slug, titleKey, excerptKey, { lang, date, category });
```

## Nouvelle page publique

1. `src/app/ma-page/page.tsx` (route **interne**)
2. Layout + `generateMetadata` + `getRequestLanguage`
3. Ajouter dans `sitemap.ts` (× `LOCALES`)
4. Liens : `lp("/ma-page")`
5. **Ne pas** créer de dossier `fr/` ou `en/`

---

## Switch de langue

Navbar : `setLang("FR" | "EN")` → remplace le préfixe d’URL (`/en/articles/x` ↔ `/fr/articles/x`).

---

## Checklist anti-erreur

- [ ] Aucun `href="/articles"` oublié dans le chrome
- [ ] `pageMetadata` path sans locale
- [ ] Sitemap regénéré (auto au build)
- [ ] Ancien `/articles` redirige vers `/en/articles`
- [ ] Canonical = URL avec locale
- [ ] hreflang en + fr + x-default
